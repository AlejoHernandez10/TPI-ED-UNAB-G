# 🎮 NextGame - 
### Sistema de Recomendación y Catálogo de Videojuegos

[![Python Version](https://img.shields.io/badge/python-3.10%2B-blue.svg)](https://www.python.org/)
[![Estado](https://img.shields.io/badge/estado-Primera_Entrega_OK-brightgreen.svg)]()

**NextGame** es una aplicación interactiva desarrollada en Python orientada a la búsqueda, exploración y recomendación personalizada de videojuegos. El sistema aplica estructuras de datos y algoritmos de coincidencia para procesar catálogos y ofrecer sugerencias basadas en géneros, calificaciones y similitudes.
